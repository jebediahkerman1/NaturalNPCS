# Natural NPCs skin folder

Put your Minecraft player skin PNG files in:

`<your Minecraft instance>/config/naturalnpcs/skins/`

The mod creates this folder automatically the first time the client starts.

- Add 10–30 skin PNG files (or as many as you like).
- Use standard Minecraft **64×64** player skins.
- Give each file a unique name, for example `skin_01.png`, `skin_02.png`, etc.
- NPCs receive a random skin when spawned with the NPC Stick.
- An NPC keeps its assigned skin when the world is saved and reloaded.
- If the folder is empty, NPCs use the default Steve skin.

The skin list is sorted by filename. In multiplayer, put the same skin files in the client and server instance folders so every player sees the same appearance.
